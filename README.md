# 📚 Library Management System (MS Access)

A desktop database management application created using **Microsoft Access** to manage library records, book issuing, returns, and user accounts.

---

### 🎯 Features
* 📖 **Book Management:** Track book inventory, categories, and availability.
* 🔄 **Issue & Return System:** Manage book borrowings, return dates, and fine calculations.
* 👤 **User Management:** Store and manage library member profiles.
* 📊 **Reports & Queries:** Generate dynamic reports for daily library activities.

---

### 🛠️ Tech Stack
* **Database & UI:** Microsoft Access (`.accdb`)
* **Logic:** Access SQL Queries, Forms, and Reports

---

### 🚀 How to Use
1. Download or clone this repository.
2. Open the `Library.accdb` file using **Microsoft Access 2016 or higher**.
3. Enable content/macros if prompted to allow full database functionalities.
